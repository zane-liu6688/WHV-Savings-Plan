备份 / 换设备迁移

云同步（GitHub 私有仓库 · 永久免费）

坚果云是网盘协议，浏览器出于跨域安全不允许网页直接读写，所以网页版改用 GitHub 仓库当云盘： 数据存进你自己的私有仓库里的一个 JSON 文件，免费、永久、自带历史版本，换设备填同样配置就能恢复。
令牌只保存在这台设备的浏览器里，填一次就行；只有「清除浏览器数据 / 换浏览器 / 换设备」时才需要重填，令牌本身不会过期。
